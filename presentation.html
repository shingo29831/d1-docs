コンセプト・概要

AI骨格検知 × 3Dデジタルツインによる
プライバシーに配慮した次世代リアルタイム見守りシステム

Cisco d1グランプリ 該当テーマ:
「少子高齢化・労働力不足」「安全・安心な社会の実現」
活用シスコ製品:
Cisco Meraki (MVカメラ / MTセンサー), Cisco Webex
開発背景

Cisco社員の皆様からのリアルな声

Cisco d1グランプリの中間イベントにて、複数のCisco社員の方々から
「リモートワーク中など、自宅での子供の見守りが本当に大変」
という切実な悩みを伺いました。

このリアルな課題をテクノロジーで解決したいという思いが、
本システム開発の大きな原動力となっています。

解決する課題

  • 見られる側の心理的抵抗（プライバシー問題）

    従来のカメラ映像監視では、常に監視されているというストレスを与えてしまう。

  • 監視者の心理的・肉体的負担

    複数のモニターを常時目視し続ける必要があり、見落としのリスクも高い。

  • 2D映像特有の死角や距離感の把握の難しさ

    平面の映像だけでは、対象者が危険なエリアにどれだけ接近しているか正確に把握しづらい。

ソリューション

  • カメラ映像をAI（YOLOv8）でリアルタイムに「骨格データ（座標）」へと変換。

  • 抽出した座標データを、ブラウザ上の「3D空間（デジタルツイン）」にマッピング。

  • 映像そのものは一切表示しないためプライバシーが守られ、AIが危険（転倒や危険エリア侵入）を自動検知して通知する。

各コンポーネントの役割

AI骨格検知モジュール

映像から人物のキーポイント（関節位置）のみを抽出。
映像をそのまま送るのではなく、
軽い「座標データ」に変換することで、
通信帯域を節約しつつプライバシーを完全に保護。

クラウド連携基盤

AWS IoT Coreを採用し、
AIが検知したデータを
クライアントへ双方向・低遅延で配信。
DynamoDBで履歴を安全に永続化。

3Dダッシュボード

ブラウザのみで動作する3D空間。
間取り作成、家具や危険エリアの配置を
GUIで直感的に行える。
履歴データは3Dヒートマップとして可視化。

実行要件

クライアント (監視者)

WebGLをサポートするモダンブラウザ
（Chrome, Edge, Safari等）。
PC・スマートフォン両対応。
専用アプリのインストールは一切不要。

AI推論モジュール

環境: Python 3.x, OpenCV, Ultralytics
インフラ: AWS EC2 (t2.small)
※Meraki MVカメラ内蔵のエッジAIでは
骨格解析がサポートされていないため、
映像ストリームを取得しEC2上で推論を実行。
現在はt2.smallで稼働中。

クラウド連携基盤

AWSサービス:
IoT Core, DynamoDB, API Gateway, Cognito

サーバーレスアーキテクチャを採用し、
待機コストを最小化。

ビジネス価値と展望

圧倒的なプライバシー保護

介護施設や保育園、病院など、
これまで「見られる側の心理的抵抗」により
カメラを置きたくても置けなかった場所への
導入が可能になります。

汎用性と水平展開

危険エリアの侵入検知や転倒検知の仕組みは、
工場や建設現場での安全管理など、
他業界へも容易に展開可能であり、
幅広いビジネス価値を提供します。
